## 1. 开机自启动

>Windows 系统的启动文件夹有两种，分别对应当前用户和所有用户：

| 类型 | 路径 | 快速打开方式 |
| :-- | :-- | :-- |
| **当前用户** | `C:\Users\<用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` | `Win+R` → 输入 `shell:startup` |
| **所有用户** | `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup` | `Win+R` → 输入 `shell:common startup` |

- **当前用户启动文件夹**：存放于此的程序快捷方式，仅在当前用户登录时自动启动。
- **所有用户启动文件夹**：放置在此文件夹中的程序快捷方式，会在任何用户登录系统时都自动启动。

## 2. 恢复 Windows 资源管理器

>当在任务管理器中结束 Windows 资源管理器后，桌面和任务栏会消失，可通过以下步骤恢复：

1. 按下 `Ctrl + Shift + Esc` 打开 **任务管理器**
2. 点击 **文件** 菜单，选择 **运行新任务**
3. 在弹出窗口中输入 `explorer.exe`，点击 **确定**

执行后，Windows 资源管理器将重新启动，桌面和任务栏通常会恢复显示。

## 3. 导出文件夹内文件名到列表

### 方法一：PowerShell（推荐）

>按住 `Win + R`，输入 `powershell` 回车，或在文件夹空白处按住 `Shift + 右键`，选择"在此处打开 PowerShell 窗口"。

```powershell
# 导出文件名到 CSV
Get-ChildItem | Select-Object Name | Export-Csv -Path "文件名列表.csv" -Encoding UTF8 -NoTypeInformation

# 若需要带修改日期
Get-ChildItem | Select-Object Name, LastWriteTime | Export-Csv -Path "文件名_带日期.csv" -Encoding UTF8 -NoTypeInformation
```

执行后生成 CSV 文件，Excel 可直接打开。

### 方法二：CMD（适合简单需求）

>打开 cmd，进入目标文件夹（`cd 路径`），输入：

```cmd
dir /b > files.txt
dir /b /a-d > filenames.txt    # 导出文件（不含文件夹）
dir /b /s > filenames.txt      # 包含子文件夹（带路径）
```
| 参数 | 说明 |
| :-- | :-- |
| `/b` | 只显示纯文件名，无多余信息 |
| `/a-d` | 只导出文件（不含文件夹） |
| `/s` | 包含子文件夹（带完整路径） |
也可以在文件管理器地址栏直接输入 `cmd` 回车，快速进入当前目录的命令行。

## 4. Windows 杀掉端口对应进程
>若需要停止某个后台服务进程，需要先找到端口对应的PID，再通过PID结束进程，具体命令如下，区分**cmd**和**powershell**命令：

>如果是CMD：
```cmd
netstat -ano | findstr "端口号"
taskkill /F /PID 这里填PID
# '/F'参数强制杀死
```
示例：`netstat -ano | findstr "8080"`
最后一列数字就是**PID**
 
> 如果是 PowerShell：
```powershell
netstat -ano | findstr "8080"
# 或者
Get-NetTCPConnection -LocalPort 8080
Stop-Process -Id PID -Force
```

>注意：结束进程前需确认该进程是否是windows服务进程，若强制结束windows服务进程，可能导致设备异常。
>可以通过遍历所有 Windows 服务，匹配 PID，**只查系统服务进程**。
```cmd
sc queryex | findstr PID
```
```PowerShell
Get‑WmiObject Win32_Service | Where‑Object {$_.ProcessId ‑eq 你的PID}
```
- 如果返回结果：有服务名，说明是 Windows 服务，优先用 `net stop 服务名` 优雅停止，不要直接 taskkill 杀 PID。
- 如果**没有任何输出**：代表只是普通进程（你的 node/docsify 就属于这种），直接 taskkill 杀 PID 即可。
