
# Linux 常用命令集合

## 1. 文件传输
> 通过 ZMODEM 协议可以在终端中进行文件上传与下载。
```bash
yum install lrzsz -y  # 安装命令
rz -bye  # 上传命令
sz file1 file2 file3  # 下载命令
```

## 3. 压缩解压
> tar、zip/unzip
> tar 命令打包压缩。tar 格式只是将文件打包，并没有压缩。bz2 的压缩率最高。

### 压缩

```bash
tar -cvf [文件名].tar [文件目录]      # 打包成 .tar 文件
tar -jcvf [文件名].tar.bz2 [文件目录]  # 打包成 .bz2 文件
tar -zcvf [文件名].tar.gz [文件目录]   # 打包成 .gz 文件
```

### 解压缩

```bash
tar -xvf [文件名].tar                  # 解压到当前目录
tar -xvf [文件名].tar -C [文件目录]      # 解压到指定目录
tar -jxvf [文件名].tar.bz2 -C [文件目录] # 解压 .bz2 文件到指定目录
tar -zxvf [文件名].tar.gz -C [文件目录]  # 解压 .gz 文件到指定目录
```

### 参数说明

| 参数 | 说明 |
| :--: | :-- |
| `-c` | 建立新的压缩文件 |
| `-x` | 从压缩的文件中提取文件 |
| `-z` | 支持 gzip 解压文件 |
| `-j` | 支持 bzip2 解压文件 |
| `-v` | 显示操作过程 |
| `-f` | 指定压缩文件 |
| `-C` | 指定解压目录（该目录必须存在） |


## 4. 进程与端口
> 通过 nc（netcat）进行端口连通性测试：

```bash
# 机器一：打开端口监听
nc -ul port

# 机器二：建立连接
nc -u ip port
```
输入任意内容，若收到相应内容，则说明网络连通。

> netstat 是一个命令行工具，可以提供有关网络连接的信息。
```bash
netstat -anp                  # 查看所有连接
netstat -tnlp | grep :80      # 查看 80 端口占用
```
| 参数 | 说明 |
| :--: | :-- |
| `-t` | 显示 TCP 端口 |
| `-u` | 显示 UDP 端口 |
