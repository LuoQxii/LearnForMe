## 环境变量
```bash
# 查看环境变量
env
# 查看环境变量文件
cat /etc/profile
# 修改环境变量
vi /etc/profile
export PATH=$PATH:路径
# 使修改生效
source /etc/profile
# 验证环境变量
echo $PATH
```
## 挂载

> NFS服务管理命令
```bash
systemctl start nfs.service       # 启动 NFS 服务
systemctl restart nfs.service     # 重启 NFS 服务
systemctl start rpcbind.service   # 启动 rpcbind 服务
```
>挂载操作
```bash
umount -f [路径]    # 强制解除挂载
umount -a           # 恢复挂载
```
>Linux 挂载 Windows 共享目录
```bash
mount -t cifs -o username="用户名",password="密码",uid=2001,gid=2001 //windowsIP/windows路径 /linux路径
```
> 配置文件

| 文件 | 说明 |
| :-- | :-- |
| `/etc/exports` | 记录允许挂载授权信息 |
| `/etc/fstab` | 记录挂载点配置 |

## 防火墙
> firewalld 服务管理命令。
```bash
systemctl enable firewalld.service    # 设置开机启用防火墙
systemctl disable firewalld.service   # 设置开机禁用防火墙
systemctl start firewalld             # 启动防火墙
systemctl stop firewalld              # 关闭防火墙
systemctl status firewalld            # 检查防火墙状态
```

### 清理内存缓存
>当swap过大时可通过以下命令进行释放，生产环境存在风险，需要谨慎。
```bash
echo 1 > /proc/sys/vm/drop_caches   # 清理页面缓存
echo 2 > /proc/sys/vm/drop_caches   # 清理目录项和 inode 缓存
echo 3 > /proc/sys/vm/drop_caches   # 清理所有缓存
```

### yum 指定本地源

```bash
cd /etc/yum.repos.d/                                    # yum 仓库配置文件目录（只保留 Local）
vi /etc/yum/pluginconf.d/subscription-manager.conf      # 禁用 subscription-manager 插件（将参数改为 0）
yum clean all                                           # 清理所有 yum 缓存
yum makecache                                           # 重新生成 yum 缓存
```

### 常用命令安装

```bash
yum install rpcbind nfs-utils     # 安装 NFS 和 rpcbind 服务
yum -y install gdb                # 安装 gdb 应用包（包含 gcore 命令）
yum list | grep zip               # 查看 zip/unzip 命令安装列表
yum install zip                   # 安装 zip
yum install unzip                 # 安装 unzip
yum install lsof                  # 安装 lsof
```
