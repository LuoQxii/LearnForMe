## 1. Binlog 解析

### ① 将 binlog 解析为 SQL 语句

```bash
mysqlbinlog --no-defaults --base64-output=decode-rows -vvv \
  --start-datetime="2023-04-28 16:30:00" \
  --stop-datetime="2023-04-28 17:30:00" \
  /mysql/log/mysql-bin.028706 > /mysql/backup/binlog_0515.sql
```

### ② 统计 DML 操作次数（Top 10）

解析二进制日志文件，筛选出 `UPDATE`、`INSERT`、`DELETE` 操作，使用 `awk` 处理后统计每种操作的次数并排序：

```bash
mysqlbinlog --no-defaults --base64-output=decode-rows -vv mysql-bin.070951 \
| awk '/UPDATE|INSERT|DELETE/{
    gsub("###","");
    gsub("INSERT.*INTO","INSERT");
    gsub("DELETE.*FROM","DELETE");
    count[$1" "$2]++
  }
  END{
    for(i in count) print i,"\t",count[i]
  }' \
| sort -k3nr | head -n 10
```

### ③ 统计关键字出现次数

```bash
grep -o "关键字" file | wc -l
```

### ④ 从 SQL 文件中提取特定操作

```bash
## 提取 UPDATE 操作到日志文件
egrep "# UPDATE" xxx.sql > xxx_update.log

## 从日志中筛选 INSERT 并统计表名出现次数
egrep "### INSERT" xxx_update.log | awk -F " " '{print $4}' | sort | uniq -c
```
