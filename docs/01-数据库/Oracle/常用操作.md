
## 用户与登录

### 重置 SYS 用户密码

#### 1. 备份原密码文件

Oracle 的密码文件存储了拥有 `SYSDBA` 和 `SYSOPER` 权限用户的密码信息，默认路径在 Oracle 安装目录下的 `database` 文件夹中，文件名为 `PWD<sid>.ora`（`<sid>` 代表数据库实例名）。

将该密码文件复制到其他安全位置进行备份，例如 `D:\oracle_backup\PWDORCL_bak.ora`。

#### 2. 使用 orapwd 工具修改密码文件

以管理员身份打开命令提示符，进入 Oracle 安装目录下的 `bin` 文件夹，执行：

```plaintext
orapwd FILE=C:\oracle\product\19.0.0\dbhome_1\database\PWD<sid>.ora PASSWORD=新密码 FORCE=Y
```

| 参数 | 说明 |
| :-- | :-- |
| `FILE` | 密码文件路径和名称，须与原文件一致 |
| `PASSWORD` | 新密码，需满足 Oracle 密码复杂度要求（至少 8 位，含大小写字母、数字、特殊字符） |
| `FORCE=Y` | 若密码文件已存在则强制覆盖 |

#### 3. 验证新密码

```plaintext
sqlplus SYS/新密码 AS SYSDBA
```

登录成功则密码重置完成；若失败，检查操作步骤或查看 Oracle 安装目录下的日志文件。

### 服务端登录 SYS 用户

```plaintext
sqlplus sys/密码@数据库连接串 as sysdba
```

示例：`sqlplus sys/yourpassword@orcl as sysdba`

## AWR 报告

### 生成 AWR 报告（TXT 格式）

在 `SQL>` 提示符下执行：

```sql
@?/rdbms/admin/awrrpt.sql
```

按提示依次输入：

| 输入项 | 说明 |
| :-- | :-- |
| DBID | 直接回车自动获取当前数据库 DBID |
| 实例号 | 单实例直接回车；RAC 环境选择对应实例号 |
| 起始快照编号 | 输入 `begin_snap_id` |
| 结束快照编号 | 输入 `end_snap_id` |
| 报告文件名 | 回车使用默认名，或输入自定义路径（如 `D:\awr\my_awr_report.txt`） |

### 生成 AWR 报告（HTML 格式）

```sql
@?/rdbms/admin/awrrpti.sql
```

操作流程与 TXT 格式类似，最终生成 `.html` 文件，可用浏览器打开查看。

### 生成快照与验证

#### 1. 调用存储过程生成快照

```sql
BEGIN
  DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT;
END;
/
```

#### 2. 验证快照生成

```sql
SELECT snap_id, snap_time
FROM dba_hist_snapshot
ORDER BY snap_id DESC;
```

## Database Link（DBLINK）

DBLink（Database Link）是 Oracle 中的数据库对象，用于实现本地数据库与远程数据库之间的连接。通过 DBLink，本地用户可直接访问远程数据库中的数据，无需手动登录远程库。

### 1. 权限要求

| 类型 | 所需权限 | 授权命令 |
| :-- | :-- | :-- |
| 私有 DBLink（仅创建者可用） | `CREATE DATABASE LINK` | `GRANT CREATE DATABASE LINK TO 用户名;` |
| 公共 DBLink（所有用户可用） | `CREATE PUBLIC DATABASE LINK` | `GRANT CREATE PUBLIC DATABASE LINK TO 用户名;` |

### 2. 创建 DBLink

需知道远程数据库的 IP 地址/主机名、端口、服务名（或 SID），以及远程用户名和密码。

```sql
-- 创建私有 DBLink
CREATE DATABASE LINK 链接名
CONNECT TO 远程用户名 IDENTIFIED BY 远程密码
USING '远程数据库连接字符串';

-- 创建公共 DBLink（加 PUBLIC 关键字）
CREATE PUBLIC DATABASE LINK 链接名
CONNECT TO 远程用户名 IDENTIFIED BY 远程密码
USING '远程数据库连接字符串';
```

**连接字符串的两种写法：**

1. 使用 `tnsnames.ora` 中的服务名（推荐，需提前配置 tns）：直接写服务名。
2. 直接写连接描述符（无需配置 tns）：

```plaintext
'(DESCRIPTION =
  (ADDRESS = (PROTOCOL = TCP)(HOST = 远程主机IP)(PORT = 端口号))
  (CONNECT_DATA = (SERVICE_NAME = 远程数据库服务名))
)'
```

### 3. 验证 DBLink

```sql
SELECT * FROM remote_table@REMOTE_LINK;
```

查询成功说明 DBLink 创建正常；若失败，检查网络连通性、账号密码或连接字符串。

### 4. 查看已创建的 DBLink

```sql
SELECT * FROM USER_DB_LINKS;   -- 当前用户拥有的私有 DBLink
SELECT * FROM ALL_DB_LINKS;    -- 当前用户可访问的所有 DBLink
SELECT * FROM DBA_DB_LINKS;    -- 数据库所有 DBLink（需 DBA 权限）
```

### 5. 删除 DBLink

```sql
DROP DATABASE LINK 链接名;           -- 删除私有 DBLink
DROP PUBLIC DATABASE LINK 链接名;    -- 删除公共 DBLink
```

## 同义词

同义词（Synonym）是 Oracle 中数据库对象的别名，用于简化对表、视图、存储过程、DBLink 等对象的引用。

### 核心作用

| 作用 | 说明 | 示例 |
| :-- | :-- | :-- |
| 简化复杂名称 | 用简短别名替代过长或含特殊字符的对象名 | `emp` 代替 `EMPLOYEE_DETAILS_2023` |
| 隐藏对象位置 | 屏蔽 `@dblink` 语法，让远程表看起来像本地表 | `SELECT * FROM 同义词` 代替 `SELECT * FROM 远程表@dblink` |
| 统一访问方式 | 对象位置或名称变更时，只需修改同义词指向 | 无需修改引用该对象的 SQL 语句 |

### 创建与使用

```sql
-- 为本地表创建私有同义词
CREATE SYNONYM emp FOR employee;

-- 为远程表（通过 DBLink）创建私有同义词
CREATE SYNONYM remote_emp FOR emp@remote_link;

-- 创建公共同义词（所有用户可访问）
CREATE PUBLIC SYNONYM pub_dept FOR dept@public_link;
```

```sql
-- 使用同义词访问原对象
SELECT * FROM emp;           -- 等价于 SELECT * FROM employee
SELECT * FROM remote_emp;    -- 等价于 SELECT * FROM emp@remote_link
```
